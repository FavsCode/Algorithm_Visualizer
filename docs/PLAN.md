### Problem/Solution

Learning and understanding CS algorithms is difficult, especially with the theory and buzz words that go into the explainations.

Many people are visual learners, and written explainations with animated pictures would clear up misunderstandings, making an algorithm visualizer a proper solution.

### MVP (minimum viable project) Requirements

After one week, have...

- At least one algorithm to simulate
- An understanding of the algorithm
- A crude representation of the algorithm
- A way to print all of this in the command-line, not necessarily in real-time
- The most basic README of all time

### Project Requirements to Ship/Complete

- [] Understand/explain 5 algorithms
- [] Create the code for the algorithms **FROM SCRATCH**
- [] Plan/implement the visual representation
- [] Have a menu with options to view each algorithm
- [] Have the demonstration be autonomous, with a few 'continue?' prompts
- [] Implement progressive visuals which go along with the code-flow/explaination
